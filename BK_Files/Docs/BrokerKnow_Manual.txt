Welcome to BrokerKnow! With the increase in complexity of the brokerage procedure it is vital to have a system that automates most if not all the processes involved in the business.
Broker Know is a comprehensive brokerage system well designed to meet the needs of your company and make efficient all the operations required for a properly working brokerage process.
This user manual has been written for the purpose of aiding the users towards their understandability of the system- Brokerknow for their benefit to contribute to their better performance and friendly working environment.
Find out more by reading through the manual!

P4 or windows 2002 or higher
To Start BrokerKnow
1. Enter your username and password in the text boxes provided.
2. Click login
BrokerKnow starts up
The main window will appear as shown below.
To Quit BrokerKnow
Choose the close button at the top of the bottom of the page.
Click OK
BrokerKnow closes
This section describes BrokerKnow menu commands used in the Input/Modify function. Each interface under the menu is described
To Add a New Record
Click the New command button
Fill in the information on the add Client Information dialogue box that appears.
Click Save
The new record will be saved
To Delete a Record
Select the record you want to delete
Click the Delete command button
A warning will appear requiring you to confirm the deletion.
If you are sure you want to delete click Yes else click No
To Edit a Record
Select the record you would like to edit
Click Edit
An Edit Client Information dialogue box appears on your screen
Edit the Information as required
Click Save to retain the changes else click Cancel to maintain the information
s original state.
To Sort Records
Click Sort
A Sort web page dialog appears
Specify the sort criteria as desired
Click on the Sort command on the Sort web page dialog
The records appearing on the screen will be sorted
Click Close to close the web page dialog box
To Filter Records
Click Filter
A Filter web page dialog appears
Fill in your filter qualification details
Click on Filter on the filter web page dialog
Click Close to close the web page dialog
To Cancel a Filter
Click the Cancel Filter command at the bottom of the screen
This returns the records to their original view before the filter.
To Search
BrokerKnow search function is designed to meet both simple and complex searches by allowing the users to use up to three fields to perform a search.
Click the Search command button
Specify the criteria for the search in the Search web page dialog.
Click the Search command on the web page dialog
A search web page dialog like the one below appears.
Note: All new, delete, edit, sort, filter and search tabs will function in the same way as discussed above.

Joint Clients
These are clients who trade in shares under a joint account. The names of both the joint account holders should appear separated by AND.
The CDS Number, Last Names, Other Names, Date of Birth, Address (One address for the joint account) and ID Number or Passport numbers are a must have
Corporate Clients
Refers to corporate bodies. These are companies that have been registered under the corporate act.
The CDS Number, Last Name, Other Names, Date of Incorporation, Address and Certificate of incorporation number will be mandatory.
Institution
Refer to any other big company that does not fall under corporate.
CDS Number, Last Name, Other Names, Date of establishment, Address and a number that uniquely identifies them if they do not have a Certificate number.
For corporate bodies and institutions, a contact name will be required.

After the trade of securities on the floor, there might be trades that do not appear on the CDS file (Unmatched trades) but appear on BrokerKnow. Other discrepancies may also exist and this calls for sorting out trades.
To be able to view unmatched trades
On Operations Reports, select Daily Trades
Click the View Unmatched Command button
There will be several reasons why the trade is unmatched:
The order balance is less than or equal to zero
Trade quantity is greater than order balance
Invalid client CDS
Invalid Security Code
Order Held
Broker not found
Consider the reason why the trade is unmatched
Solve the situations accordingly
Case 1: Order Balance < = 0, means that there is no pending order. i.e. that all orders have been executed.
Solution:  Register a new order
Follow the steps for registering an order. Refer to Customer Service>Registering an Order
Case 2: Trade Quantity > Order Balance means that the balance on an order in BrokerKnow is greater than what was traded.
Solution:
Increase the balance on the order to reflect what was traded.
Case 3: means that the client
s CDS cannot be found on the system
Register the client on the system or change the client CDS account on the system accordingly.
Follow the steps of registering a client. Customer Service>Registering a Client
Case 4: means that the security code cannot be found on the system i.e. that the security code on the file is different from that in the system.
Change the security code on the system accordingly
Case 5: The trade is unmatched because the order is still held.
Release the order
On Front Office, Operations or Management menus go to Release Orders
Orders that have been held will normally appear on the grid
Check the checkbox of the order that you want to release.
The order should no longer appear in the list of held orders.
Case 6: Means that the Broker code on the file cannot be found in BrokerKnow
Solution: Register the Broker

Ideally the system does not accept duplicate orders. However, if for an unusual reason it does, BrokerKnow provides the Duplicate Order function  to detect such orders.
Using the same scenario above, if the first order has been cancelled the system should be able to accept the second order.
